# Local illustrative assets

`binnenhof.svg`, `canal.svg`, `nature.svg`, `care.svg`, `skyline.svg` and `avatar.svg` were created for this prototype as original vector illustrations.

They are **illustrations**, not photographs, official branding, verified news imagery or a portrait of a real user. The Binnenhof image is a stylized architectural impression, not a geospatially or architecturally exact reconstruction. The avatar is fictional.

No external image service is contacted at runtime. The uploaded reference provides the visual direction; original photographic and logo source files were not supplied. Public Amsterdam and Den Haag design-system repositories were checked but did not provide suitable locally reusable photographs for these screens. Restricted image hosts were not bypassed.

The map asset, if present, has its own provenance supplied by the map implementation.
